# Desbravadores

## Sobre esta versão

Este repositório é uma **expansão** do projeto original **DesbravadoresTeste**, desenvolvido por [Arthur Vieira Bruske](https://github.com/ArthurVieiraaa) e [Silas Cassiano Tristoni](https://github.com/SilasTristoni) como projeto de extensão da **Faculdade Senac Joinville**.

Repositório original: https://github.com/SilasTristoni/DesbravadoresTeste

O objetivo desta versão é dar continuidade ao trabalho da equipe original, corrigindo problemas existentes e adicionando novas funcionalidades, sem remover nada do que já foi construído.

___________________________________

Projeto de extensão da Faculdade Senac Joinville, destinado ao clube regional de escoteiros "Asas da Liberdade" pertencentes ao grupo "Desbravadores", com colaboração do diretor Sérgio Ricardo Bachmann.
___________________________________

Será desenvolvido uma aplicação com o objetivo de facilitar a rotina dos integrantes do clube, desde tarefas até personalizações de perfil. Desta forma, esse projeto busca otimizar e tornar mais intuitivos as tarefas simples e complexas realizadas no dia a dia do clube, por meio de gamificações e design interativo com os usuários do aplicativo, sejam crianças, jovens, responsáveis e instrutores.
___________________________________

### 📋 - Estrutura do projeto

- `desbravadores-api/` — backend em Spring Boot (Java 17).
- `desbravadores-frontend/` — frontend em HTML/CSS/JS puro.

### ⚙ - Como rodar

**Backend**
1. Suba um MySQL 8 (porta 3306, usuário `root` sem senha, banco `desbravadores_db`).
2. Dentro de `desbravadores-api/`, rode `./mvnw spring-boot:run`.
3. A API fica disponível em `http://localhost:8080`.

**Frontend**
1. Abra a pasta `desbravadores-frontend/` com o Live Server (ou extensão equivalente) na porta 5500.
2. Acesse `login.html`.
